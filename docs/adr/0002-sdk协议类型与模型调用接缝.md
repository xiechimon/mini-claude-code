# ADR-0002：复用 SDK 协议类型，在模型调用处建立接缝

s01 的 Conversation History、模型消息和 content block 直接使用官方 `anthropic-java` 的协议类型，不再建立一套项目自有 sealed
类型；Agent Loop 只依赖小型 `ModelClient` 接口，生产 adapter 调用官方 SDK，测试 adapter 返回受控消息。SDK 已提供前向兼容的
content-block 联合类型以及 `Message.toParam()` 转换，重复建模会增加协议同步成本；把接缝放在真正外部的模型调用处，则能隔离网络并让核心循环通过
fake adapter 验证。`ModelClient` 的精确接口为 `Message create(MessageCreateParams request)`：Agent Loop 负责构造并持有完整请求不变量，
production 与 fake adapter 只负责返回下一条模型消息。
